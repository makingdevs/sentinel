# Mapa de interacción

| Pantalla | Acción | Resultado |
| --- | --- | --- |
| Cámaras / historial local | Abrir «Canales» | Lista de canales con color, sucursal, fuentes configuradas, estado y última captura |
| Canales | Crear / editar | Formulario con vista previa del color y reemplazo opcional de URLs |
| Canales | Archivar / restaurar | Confirmación, cambio de disponibilidad y reconciliación de procesos |
| Cámaras | Elegir canal | Tarjeta y etiqueta con color del catálogo; indicador independiente |
| Historial | Elegir día, cámara o intervalo | Barras segmentadas por cámara con leyenda; grupos, imágenes y detalle con el mismo color |
